# 📚 Library Management System

## 📖 About The Project

This project is a simple Library Management System built using
HTML, CSS, and TypeScript.

The project allows users to view books, search for books by title
or author, filter books by category, and change the availability
status of each book.

The project also demonstrates important Object-Oriented Programming
concepts in TypeScript such as:

- Classes
- Encapsulation
- Inheritance
- Polymorphism
- Methods
- TypeScript data types


## ✨ Features

The landing page provides the following features:

- Display books as cards
- Search books by title or author
- Filter books by category
- Change book availability
- Support Reference Books
- Display the location code of Reference Books
- Responsive design for different screen sizes
- Interactive hover effects and transitions


## 🛠 Technologies Used

- HTML5
- CSS3
- TypeScript
